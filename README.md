# WallGo

Быстрый и легковесный сервис для публикации текстов (микроблог), написанный на Go. 

## Технологический стек

* **Language:** Go (v1.26) — высокая производительность и минимальное потребление ресурсов.
* **Routing:** `go-chi/v5` — легковесный, идиоматичный и производительный роутер, совместимый со стандартным `net/http`.
* **Database:** PostgreSQL 15 — надежное персистентное хранение данных.
* **Caching:** Redis 7 — кэширование горячих данных для снижения нагрузки на СУБД.


## Запуск локально

Приложение отлично работает напрямую на вашем компьютере. По умолчанию оно пытается подключиться к **PostgreSQL** и **Redis** на `localhost` с дефолтными настройками, прописанными в коде.

### 1. Подготовка баз данных

Перед запуском убедитесь, что локальные службы активны:

* **Redis**: должен работать на порту `6379` (без пароля).
* **PostgreSQL**: должен работать на порту `5432`. Вам нужно заранее создать базу данных:

```bash
  psql -U postgres -c "CREATE DATABASE pastebin_db;"

 ```

### 2. Как запустить готовый бинарник (GitHub Releases)

Актуальные скомпилированные файлы под **Linux, Windows и macOS** автоматически доступны
во вкладке **Releases** GitHub-репозитория.

1. Скачайте подходящий файл из последнего релиза.
2. Перейдите в терминале в папку со сканчанным файлом.
3. Установите переменные окружения (если ваши пароли отличаются от дефолтных) и запустите:

```bash
# 1. Настройка доступов (опционально)
export DB_PASSWORD="secret"  # Укажите ваш реальный пароль от Postgres

# 2. Выдача прав на запуск (для Linux/macOS)
chmod +x wallgo-linux-amd64

# 3. Старт приложения
./wallgo-linux-amd64
```

> **Важно:** Бинарник ищет статичные файлы фронтенда в папке `./web`. Убедитесь, что запускаете его из корня проекта, либо скопируйте папку `web` туда, где лежит ваш бинарный файл.

---

### 3. Справочник переменных окружения

Если вам нужно переопределить стандартные настройки, задайте их перед запуском:

| Переменная | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `DB_HOST` | Хост базы данных PostgreSQL | `localhost` |
| `DB_PORT` | Порт PostgreSQL | `5432` |
| `DB_USER` | Пользователь базы | `postgres` |
| `DB_PASSWORD` | Пароль от базы | `secret` |
| `DB_NAME` | Имя базы данных | `pastebin_db` |
| `REDIS_HOST`| Хост службы Redis | `localhost` |
| `REDIS_PORT`| Порт службы Redis | `6379` |

После запуска веб-интерфейс и API будут доступны по адресу: **http://localhost:8080**
