# WallGo

Легковесный сервис для публикации и обмена постами (микроблогинг), написанный на Go с упором на чистую архитектуру и кэширование.

---


## 🛠 Технологический стек

* **Language:** Go (v1.26) — высокая производительность и минимальное потребление ресурсов.
* **Routing:** `go-chi/v5` — легковесный, идиоматичный и производительный роутер, совместимый со стандартным `net/http`.
* **Database:** PostgreSQL 15 — надежное персистентное хранение данных.
* **Caching:** Redis 7 — кэширование горячих данных для снижения нагрузки на СУБД.
* **DevOps & CI/CD:** Docker, Docker Compose, GitHub Actions.

---

## 📂 Структура каталогов

```text
├── cmd/
│   └── apiserver/       # Точка входа, инициализация и запуск приложения
├── internal/
│   ├── handler/         # HTTP-слой (контроллеры, обработчики запросов, маршруты)
│   ├── model/           # Доменные модели и сущности бизнеса
│   └── repository/      # Слой работы с данными (интерфейсы и имплементация БД/Redis)
├── web/                 # Статические файлы фронтенда (HTML/CSS/JS)
├── Dockerfile           # Инструкция многоэтапной сборки контейнера
├── docker-compose.yml   # Оркестрация сервисов (App, Postgres, Redis)
└── README.md            # Документация проекта

```

## 🛠 Запуск

Если вы хотите скачать исходный код и запустить проект локально:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/liziwinc/WallGo.git
cd WallGo
```


2. Запустите инфраструктуру:
```bash
docker compose up -d
```


3. Для остановки сервисов и удаления контейнеров:
```bash
docker compose down
```
